# Designing the windows

Placeholder notes. Every open window is a path, and the URL holds the stack:

```
/?w=posts,posts/hello-world,now-playing
```

## Two kinds of windows

1. **Apps** like Finder and Now Playing render in the browser, so opening one is instant.
2. **Documents** like this post render on the server, so they arrive as HTML that search engines can read.

The window doesn't care which kind it holds. Read the [first post](/posts/hello-world)
or [about the dithering](/posts/on-dithering).
