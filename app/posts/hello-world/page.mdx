# Hello, world

This is a **placeholder post**. Every post is a `page.mdx` file in `app/posts`. From the
Posts folder it opens as a window; its own link,
[garox.org/posts/hello-world](/posts/hello-world), opens it fullscreen on top of the desktop.

Try a few things:

- Click the **zoom box** in the top-right corner to switch between a window and fullscreen.
- Open [another post](/posts/designing-windows). It opens the same way you're reading this one.
- Open [what I'm listening to](/now-playing). Every icon on the desktop has its own URL.
- Press **Back**. You land where you were, scrolled to the same spot.
- Use **Copy Link** below and paste it into a new tab.

> The address bar always says what's on top: the path is the fullscreen page,
> and `?w=` remembers the windows behind it.
