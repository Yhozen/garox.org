# Designing the windows

Placeholder notes. The URL describes the whole desktop:

```
/posts/designing-windows?w=posts,now-playing
 └─ fullscreen, on top    └─ windows behind it
```

## Two layers

1. **The path** is a real page. Posts are MDX files, rendered ahead of time and served from the CDN.
2. **The `?w` parameter** is the stack of windows. Opening, moving and closing them never leaves the browser.

The zoom box moves something between the two. Read the [first post](/posts/hello-world)
or [about the dithering](/posts/on-dithering).
